### RU

Для отображения интерфейса IMGUI

1) Убедитесь, что в LSEngine\Chapter 9 Texturing\Try2\x64\Debug существует файл .imgui_on
2) При запуске приложения включайте/выключайте отображение Imgui на ~

### EN

To display the IMGUI interface

1) Make sure that the .imgui_on file exists in LSEngine\Chapter 9 Texturing\Try2\x64\Debug
2) When starting the application, turn on/off Imgui display on ~
